# 剧集缺集审计 — 设计记录

> **实施请直接看 [`library-audit-spec.md`](library-audit-spec.md)**，那份是可独立执行的规格。
> 本文只保留设计演进过程与结论，避免和规格文档产生分歧。

## 结论（2026-11-04 定稿）

1. **只读工具**，不是 MCP 工具，不进 Agent 工具链。
2. **数据源分工**：飞牛负责"本地有哪些集"（数 `episode/list` 的行），TMDB 负责"已播出多少集、是否完结"（实时查询）。
   飞牛里的 `number_of_episodes` / `status` 是入库时的快照，**一律不用**。
3. **TMDB 全部重新匹配**：按 `imdb_id → 标题+年份打分` 的级联，"未匹配"是待解决项而不是终态。
4. **三分类 + 两个补充桶**：正常完结 / 缺集 / 待完结，外加「TMDB 无此条目」与「待确认匹配」。

## 验证过程

| 日期 | 样本 | 结论 |
|---|---|---|
| 11-03 | `search/list?q=繁花` | 确认关键词检索可用，含本地季集数 |
| 11-04 | `item/list`（电视剧库 50 条） | 库内分页可行；发现 `status="1"` 未匹配、本地集数可超 TMDB |
| 11-04 | `item/{guid}`、`episode/list/{guid}` | 分集层可用，但分集行的计数字段全为 0 |
| 11-04 | `season/list/{guid}`（美人余） | 多季遍历入口确认 |
| 11-04 | `episode/list`（美人余，缺第 13 集） | **缺集时列表少行，不补占位** → 集合差集可精确缺集定位 |
| 11-04 | 美人余三级计数（14 / 13 / 13 行） | **计数字段不可信，只能数行** |

最后两条是决定性的：它们同时证明了"方案可行"和"天真实现会算错"。
